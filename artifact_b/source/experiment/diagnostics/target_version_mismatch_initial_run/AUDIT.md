# Initial Stage 2 run excluded after target audit

The first Stage 2 fine-tuning run is preserved here for audit only. It used a payload-regenerated QR matrix rather than the matrix in the photographed physical code. An inspected example had a clean-reference `straight_qrcode` matrix of 33x33 modules while the re-generated target was 25x25 modules. Because QR version, error correction, and mask are not specified by payload alone, the supervision was misaligned. These checkpoints and metrics are invalid for method comparison and are not used in the final results. The corrected Stage 2 run uses a paired Clean capture whose OpenCV and ZXing decoded payloads both match the recorded value; non-verified references are excluded from training. Stage 2 MER remains unreported because the sampled clean-image matrix is not an independent matrix annotation.
